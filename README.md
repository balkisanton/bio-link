## 🚀 Fitur Unggulan

- **Ultra Cepat & Ringan**: Murni HTML5, CSS3 kustom (modern design system), dan Vanilla JS tanpa runtime framework berat. Nilai performa 100/100 di Google Lighthouse.
- **Dukungan Dark / Light Theme**: Dilengkapi tombol beralih tema (gelap & terang) dengan penyimpanan preferensi di `localStorage` serta sinkronisasi otomatis ke tema sistem OS.
- **Mobile-First & Responsif**: Tampilan rapi dan nyaman dibuka dari smartphone, tablet, maupun layar desktop.
- **Fitur Bagikan (Share)**: Tombol interaktif dengan Web Share API (native share di HP) dan auto fallback salin ke clipboard dengan toast notifikasi.
- **Vercel Ready**: Dilengkapi konfigurasi `vercel.json` untuk clean URLs, cache header, dan security headers.

## 🌐 Cara Deploy ke Vercel

Ada 2 cara mudah untuk mendeploy website ini:

### Cara 1: Menggunakan Vercel Dashboard (Rekomendasi)
1. Buka [vercel.com](https://vercel.com) dan login menggunakan akun GitHub Anda.
2. Klik tombol **"Add New..."** lalu pilih **"Project"**.
3. Di daftar repository GitHub Anda, pilih repository **`bio-link`** dan klik **"Import"**.
4. Biarkan konfigurasi default (Framework Preset: **Other**, Build Command: kosong/default).
5. Klik **"Deploy"**.
6. Dalam hitungan detik, website bio link Anda akan online dengan domain bawaan Vercel (misal: `bio-link-balkisanton.vercel.app`) atau Anda bisa pasang custom domain Anda.

### Cara 2: 1-Click Deploy Button
Cukup klik tombol berikut:  
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/balkisanton/bio-link)

## 💻 Menjalankan Secara Lokal

Buka file `index.html` langsung di browser Anda, atau gunakan simple server:

```bash
# Menggunakan Python
python -m http.server 3000

# Menggunakan npx serve
npx serve .
```
Lalu buka [http://localhost:3000](http://localhost:3000).
